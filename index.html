A kódok otthona: GitHub

A GitHub egy online platform, ahol elmentheted a programkódodat, követheted a változásokat, együtt dolgozhatsz másokkal, és akár a saját weboldaladat is közzéteheted.

Ismerd meg! ↓

💡 Mi a GitHub lényege?

Képzeld el úgy, mint egy online műhelyt a programozóknak.

📦

Projekt tárolása

A fájljaidat egy repositoryban, azaz projektadattárban tarthatod.

🕒

Változások követése

Láthatod, mit módosítottál, és szükség esetén visszanézheted a korábbi verziókat.

🤝

Közös fejlesztés

Többen is dolgozhattok ugyanazon a projekten, és ellenőrizhetitek egymás módosításait.

🌐

Weboldalak publikálása

A GitHub Pages segítségével statikus weboldalakat tehetsz közzé az interneten.

⚙️ Hogyan működik?

A projekted útja a saját gépedtől az online adattárig.

01 · Készítés

Megírod a kódot, például egy index.html fájlban.

02 · Commit

Rögzíted a változtatásokat egy rövid leírással.

03 · Push

Feltöltöd a helyi változtatásokat a GitHubra.

04 · Megosztás

Mások megnézhetik a projektedet, vagy együtt dolgozhattok rajta.

🚀 Saját weboldal GitHub Pages segítségével

Nem kell feltétlenül fizetős tárhely! Egy egyszerű HTML-, CSS- és JavaScript-oldalt közzétehetsz a GitHub Pages használatával.

  • Hozz létre egy GitHub-fiókot.
  • Készíts egy új repositoryt.
  • Töltsd fel az index.html fájlt.
  • A Settings → Pages menüben kapcsold be a publikálást.
